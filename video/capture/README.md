Run `cd video && pnpm install && npx playwright install chromium && pnpm capture` (needs `ffmpeg` on PATH) — films the live site at https://shield-field.vercel.app into `public/clip-magic.mp4`, `public/clip-replay.mp4`, the four `public/shot-*.png`, and writes `public/clips.json` plus the exact ffmpeg commands to `capture/out/ffmpeg-commands.txt`; set `FIELD_SHIFT_URL` to film another deployment, or `LOCAL_APP_DIR=/path/to/shield_field` to fall back to `pnpm build && pnpm start` on http://localhost:3000 when the live site is unreachable.
