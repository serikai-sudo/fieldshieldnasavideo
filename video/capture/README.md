Run `cd video && pnpm install && npx playwright install chromium && pnpm capture` (needs `ffmpeg` on PATH) — films one continuous walkthrough of the live site at https://shield-field.vercel.app (map → Kostanay → Season slider 2026→2025 → field page → Water, Heat, Sowing, Replay, Confidence) into `public/tour.mp4` and writes each step's start second and click point to `public/tour.json`, plus the exact ffmpeg command to `capture/out/ffmpeg-commands.txt`; set `FIELD_SHIFT_URL` to film another deployment, or `LOCAL_APP_DIR=/path/to/shield_field` to fall back to `pnpm build && pnpm start` on http://localhost:3000 when the live site is unreachable.
